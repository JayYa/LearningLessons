架构与网络

术语含义
Origin
源		 协议 + 域名 + 端口 三者构成的元组。三者全同才算同源。http://localhost:5173 与 http://localhost:8000 不同源；localhost 与 127.0.0.1 也不同源。
CORS
跨源资源共享		 Cross-Origin Resource Sharing。服务端通过 Access-Control-Allow-Origin 等响应头，声明允许哪些源读取自己的响应。拦截动作发生在浏览器，服务端代码已执行完毕。非浏览器客户端（curl / Postman / 移动端）不受约束。MDN
Preflight
预检请求		 对于非简单请求（如带自定义头、PUT/DELETE），浏览器会先自动发一个 OPTIONS 请求问服务端“我能发吗”。这就是为什么 CORSMiddleware 里要配 allow_methods 和 allow_headers。
SPA
单页应用		 Single-Page Application。服务端只返回一个近乎空白的 HTML 外壳，之后由 JS 接管全部渲染与路由。与 Razor Pages / MVC 的服务端渲染相对。

工具链

术语含义
Dev server
开发服务器		 仅在开发期存在的进程（此处为 Vite），负责实时编译源码并交付给浏览器。不进生产环境。
HMR
热模块替换		 Hot Module Replacement。保存文件后，只把变更的模块推给浏览器并原地替换，页面不整体刷新、当前 state 得以保留。这是 dev server 存在的核心理由。
Transpile
转译		 把一种高级语言编译成另一种同层级的高级语言（TS → JS），而非编译成机器码或 IL。TS 编译器的产物仍然是人类可读的 JS。
Bundle
打包		 把成百上千个源文件与依赖合并、压缩成少数几个 .js 文件，减少浏览器的请求数。pnpm build 做的就是这件事。
venv
虚拟环境		 Python 的项目级依赖隔离机制。python -m venv .venv 创建一份独立的解释器与 site-packages；Activate.ps1 把它插到 PATH 最前面。.venv 不进版本库。
node_modules 包管理器安装依赖的落地目录，位于项目内。不进版本库，由 package.json + 锁文件（pnpm-lock.yaml）重建。pnpm 下它是一片指向全局 store 的链接，而非真实副本。

TypeScript 类型系统

术语含义
Structural typing
结构化类型		 类型之间的兼容性只看形状（有哪些属性、类型是什么），与名字、继承关系无关。TS 的默认规则。判定标准是「至少有」而非「刚好是」。
Nominal typing
名义类型		 兼容性看名字与声明的继承关系。C# / Java 的规则。两个结构相同但名字不同的 class 绝不互换。
TS 中的例外：带 private / protected 成员的 class 会按声明位置比较，等效于名义类型。
Reified
具化		 类型信息在运行时依然存在。C# 的类型是 reified 的（故有反射、is、typeof(T)）；TS 的类型不是。
Type erasure
类型擦除		 编译时把所有类型信息删除的过程。interface、type、类型注解、泛型参数编译后一个字节都不剩。运行时唯一残留的类型痕迹是 class（编译成真实的 JS 函数，故 instanceof 可用）。
Excess property check
多余属性检查		 把新鲜的对象字面量直接赋给某个类型时，TS 会额外禁止多余属性（TS2353）。先赋给变量再传则不触发。设计意图是抓拼写错误。
Type alias
类型别名		 type X = …。与 interface 高度重叠，但能给联合类型、原始类型等任意类型命名（type Id = string | number），interface 不能。
any / unknown 都表示「类型未知」。any 关闭检查，可以对它做任何事 —— 类型系统的逃生舱与主要漏洞来源（res.json() 就返回它）。unknown 是安全版：必须先收窄类型才能使用。

Python

术语含义
Decorator
装饰器		 @something 语法。它是一个函数，接收被装饰的函数、返回一个新函数。@app.get("/x") 的作用是把下面的函数注册进路由表。语法位置像 C# 的 attribute，机制却完全不同 —— attribute 是编译期元数据，装饰器是运行时的函数调用。
Type hint
类型注解		 def f(x: int) -> str: 中的注解。Python 运行时不会据此做任何检查 —— 它纯粹是给工具看的元数据。FastAPI 和 Pydantic 的做法是在运行时主动读取这些注解并据此生成校验逻辑，这正是它们「看起来像静态类型语言」的原因。
ASGI Asynchronous Server Gateway Interface。Python 异步 Web 应用与服务器之间的标准接口。FastAPI 是 ASGI 应用，Uvicorn 是 ASGI 服务器，二者靠这个约定对接 —— 类比 ASP.NET Core 应用与 Kestrel 的关系。
