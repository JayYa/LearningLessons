What is an Agent?

从「聊天机器人」到「自动完成任务」——理解 Agent 的心智模型，并构建你的第一个可运行的 C# Agent。

Agent Loop Tool Use Semantic Kernel C#

为什么你需要理解 Agent

你已经用过 ChatGPT 和 Claude——你问一句，它答一句。这很有用，但这是对话，不是自动化。

想象这样一个场景：你告诉系统「帮我查一下明天北京的天气，如果下雨就给我发一封提醒邮件」。一个聊天机器人做不到这个——它只能给你建议。但一个 Agent 可以：它自动调用天气 API、判断是否下雨、调用邮件服务，最后告诉你结果。

核心区别： 聊天机器人是被动响应的；Agent 是主动执行的。Agent 不止生成文字——它采取行动（调用 API、读写文件、发送消息），直到目标完成。

心智模型：Agent 的解剖结构

一个 Agent 由四个核心组件构成。理解这个模型，你就理解了所有 Agent 框架的底层逻辑：

┌──────────────────────────────────────────────────┐ │ AGENT │ │ │ │ ┌──────────┐ ┌──────────────┐ │ │ │ LLM │ │ TOOLS │ │ │ │ (大脑) │◄──►│ (双手) │ │ │ └────┬─────┘ └──────┬───────┘ │ │ │ │ │ │ ┌────┴─────────────────┴──────┐ │ │ │ MEMORY │ │ │ │ (短期=对话 / 长期=向量库) │ │ │ └─────────────────────────────┘ │ │ │ │ │ ┌──────────┴──────────┐ │ │ │ PLANNER │ │ │ │ (决定下一步做什么) │ │ │ └──────────────────────┘ │ └──────────────────────────────────────────────────┘

四个核心组件

① LLM（大脑）
负责理解任务、推理「该调用哪个工具」、根据工具返回结果生成回复。它不做实际动作——只做决策。
② Tools / Plugins（双手）
Agent 可以调用的函数/API。比如：查天气、发邮件、读数据库、执行代码。在 Semantic Kernel 中，这些叫 Plugins——它们就是带 [KernelFunction] 特性的 C# 方法。
③ Memory（记忆）
短期记忆 = 对话历史（Chat History），让 Agent 记得刚才说了什么。长期记忆 = 向量数据库 + 语义搜索（RAG），让 Agent 能检索海量知识。本课先聚焦短期记忆。
④ Planner（规划器）
控制执行循环——「现在该调用哪个工具？任务完成了吗？」。最简单的 Planner 就是让 LLM 自主决定每步做什么（ReAct 模式）。

核心机制：Agent Loop

所有 Agent 共享同一个底层循环：

┌──────────────┐ │ 用户输入目标 │ └──────┬───────┘ ▼ ┌──────────────┐ ┌───►│ LLM 推理 │ ◄──┐ │ │ 下一步做什么？ │ │ │ └──────┬───────┘ │ │ ▼ │ │ ┌─────────────────┐ │ │ │ 需要调用工具吗？ │ │ │ └────┬───────┬────┘ │ │ Yes │ │ No │ │ ▼ └──────┼───► 生成最终回复 → 结束 │ ┌──────────────┐ │ │ │ 执行工具/函数 │ │ │ │ 获取结果 │ │ │ └──────┬───────┘ │ │ │ │ │ ▼ │ │ ┌──────────────┐ │ └────│ 将结果反馈给 │────┘ │ LLM 继续推理 │ └──────────────┘

这个循环的关键在于：LLM 每次看到的是「原始任务 + 已执行的工具调用结果 + 对话历史」。它基于累积上下文来决定下一步。这不是魔法——它是一个设计精良的反馈循环。

动手构建：你的第一个 Agent

理论够了。现在用 .NET 10 + Semantic Kernel 构建一个能使用工具的 Agent。 我们的 Agent 有一个简单的工具：获取当前时间。用户可以用自然语言问时间。

本课产出： 一个控制台应用，其中 Agent 能理解自然语言请求并调用 C# 函数获取系统时间。这是所有 Agent 产品的最小可用骨架。

Step 1: 创建项目并添加包

dotnet new console -n MyFirstAgent
cd MyFirstAgent
dotnet add package Microsoft.SemanticKernel --prerelease
dotnet add package Microsoft.SemanticKernel.Agents.Core --prerelease
dotnet add package Microsoft.SemanticKernel.Connectors.OpenAI --prerelease

Step 2: 定义一个工具（Plugin）

工具就是加了 [KernelFunction] 特性的普通 C# 类。Agent 会自己决定何时调用它：

using System.ComponentModel;
using Microsoft.SemanticKernel;

public class TimePlugin
{
    [KernelFunction("get_current_time")]
    [Description("获取当前的系统时间，返回格式为 HH:mm:ss")]
    public string GetCurrentTime()
    {
        return DateTime.Now.ToString("HH:mm:ss");
    }

    [KernelFunction("get_current_date")]
    [Description("获取今天的日期，返回格式为 yyyy-MM-dd")]
    public string GetCurrentDate()
    {
        return DateTime.Now.ToString("yyyy-MM-dd");
    }
}
关键点： [Description] 特性不是给人看的——是给 LLM 看的。LLM 通过读取函数的名称和描述来决定「这个工具能不能帮用户完成当前任务」。写得越清楚，Agent 判断越准。

Step 3: 创建 Agent 并运行

using Microsoft.SemanticKernel;
using Microsoft.SemanticKernel.Agents;
using Microsoft.SemanticKernel.Agents.Chat;
using Microsoft.SemanticKernel.ChatCompletion;
using Microsoft.SemanticKernel.Connectors.OpenAI;

// 1. 构建 Kernel —— Agent 的"底盘"
var builder = Kernel.CreateBuilder();

// 使用 OpenAI（你需要一个 API key）
builder.AddOpenAIChatCompletion(
    modelId: "gpt-4o-mini",
    apiKey: Environment.GetEnvironmentVariable("OPENAI_API_KEY")!
);

// 注册我们的工具
builder.Plugins.AddFromType<TimePlugin>();

Kernel kernel = builder.Build();

// 2. 创建 Agent
var agent = new ChatCompletionAgent
{
    Name = "TimeAssistant",
    Instructions = """
        你是一个时间助手。当用户询问时间或日期时，使用提供的工具获取准确信息。
        回答时请用中文。如果用户问的时间是早上，请附加一句问候。
        """,
    Kernel = kernel
};

// 3. 运行对话循环
var history = new ChatHistory();
Console.WriteLine("=== 你的第一个 Agent 已就绪 ===");
Console.WriteLine("输入 'exit' 退出\n");

while (true)
{
    Console.Write("你: ");
    var input = Console.ReadLine();
    if (input?.ToLower() == "exit") break;

    history.Add(new ChatMessageContent(AuthorRole.User, input!));

    Console.Write("Agent: ");
    await foreach (var chunk in agent.InvokeStreamingAsync(history))
    {
        Console.Write(chunk.Content);
    }
    Console.WriteLine("\n");
}

Step 4: 配置 API Key 并运行

# PowerShell
$env:OPENAI_API_KEY = "sk-your-key-here"
dotnet run

# 试试这些输入：
# "现在几点了？"
# "今天是几号？"
# "现在是早上还是下午？"

发生了什么？—— 追踪 Agent Loop 的实际运作

当你说「现在几点了？」时，背后发生了这些事：

  1. 用户输入 追加到 ChatHistory：「现在几点了？」
  2. LLM 推理：读取系统提示 + 对话历史 + 可用工具列表。判断 ——「用户问时间，我需要用 get_current_time 工具」
  3. 框架拦截：Semantic Kernel 检测到 LLM 要调用函数，截获请求，实际执行 TimePlugin.GetCurrentTime()
  4. 结果回填：函数返回值（如 "14:35:22"）作为新的上下文消息追加到对话中
  5. LLM 再次推理：现在有了工具结果，LLM 基于它生成自然语言回复：「现在是下午 2 点 35 分。下午好！」
  6. 等待下一条用户输入——循环继续
你已经做到了： 你构建的系统不再只是「输入→输出」的对话——它有了 感知→推理→行动→观察→再推理 的完整闭环。这就是 Agent。
