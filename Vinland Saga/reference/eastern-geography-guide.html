🗺 东部地理术语指南

Reference — 拜占庭 · 罗斯 · 基辅 · 君士坦丁堡 · 希腊 · 俄罗斯：关系、地理与时间线

📋 总表：每个名字是什么意思？

名称类型存在时间一句话定义
君士坦丁堡
Constantinople		 城市 330–1453 拜占庭帝国首都。博斯普鲁斯海峡西岸。今日伊斯坦布尔。北欧人称 Miklagarðr（"大城"）。当时欧洲最大最富的城市，人口~40万。
拜占庭帝国
Byzantine Empire		 帝国 395–1453 东罗马帝国。自称"罗马帝国"（他们从不叫自己"拜占庭"——这是后世史学家给的名字）。维京时代版图：安纳托利亚 + 巴尔干半岛 + 希腊 + 南意大利。
希腊
Greece		 地理区域 — 在维京时代不是一个独立国家——它是拜占庭帝国的一部分。现代希腊王国 1832 年才独立。"从瓦良格人到希腊人之路"中的"希腊人"指整个拜占庭帝国（古代诺尔斯语 Grikkland = 希腊之地 = 拜占庭帝国）。
罗斯
Rus' (Русь)		 人群→政权 约9–13世纪 来自瑞典的维京人（瓦良格人）与东斯拉夫人融合形成的人群和政权。"罗斯"这个词最早指维京统治精英，后来变成他们统治的领土的名称。→ 这是"俄罗斯"名字的真正来源。
基辅
Kyiv / Kiev		 城市 约5世纪至今 第聂伯河（Dnieper）中游城市。约 882 年起成为罗斯政权的首都。北欧人称 Kœnugarðr（"船坞"）。现代乌克兰首都。
基辅罗斯
Kievan Rus'		 国家 约882–1240 以基辅为首都的罗斯政权——这是俄罗斯、乌克兰、白俄罗斯三国的共同历史前身。1240年被蒙古人灭亡。
俄罗斯
Russia		 现代国家 15世纪→至今 基辅罗斯灭亡后，政治重心从基辅北移至莫斯科。莫斯科公国（15世纪）→ 沙皇俄国（1547年）→ 今天的俄罗斯。名字来自"罗斯"，但经过了多次语言转写（见下方链条）。

🗺 地理：它们在哪儿？怎么连起来的？

🌊 "从瓦良格人到希腊人之路"（The Varangian Route）

这是连接北欧和拜占庭的贸易与军事走廊，以第聂伯河（Dnieper）为核心动脉：

🇸🇪 瑞典
Birka / Gotland → 🌊 波罗的海 → 🏔 芬兰湾 → 🌊 涅瓦河 (Neva) → 🌊 拉多加湖 (Ladoga) →
🏘 诺夫哥罗德
Holmgarðr = Rurik建国地 → 🔀 PORTAGE
（需要陆上拖船！） → 🌊 第聂伯河上游 → 🏰 基辅
Kœnugarðr = 首都 → ⚠️ 七处急流
（PORTAGE！佩切涅格人伏击点） →
🌊 黑海 → 🏛 君士坦丁堡
Miklagarðr

耗时：从基辅到君士坦丁堡约 6 周（含等待顺风和绕过急流的时间）。从瑞典到君士坦丁堡全程约 2–3 个月。

🔗 Portage（陆地运船） 在这条路线上不是可选项——是必需项。没有它，船无法从第聂伯河上游水系切换到下游，也无法绕过七处急流。

💡 伏尔加路线（东线）和 第聂伯路线（南线）——一个到伊斯兰世界，一个到拜占庭。两者都从瑞典出发，都在今天俄罗斯/乌克兰的河流系统中分叉。维京人在东方的两个贸易圈子。这就是 维京白银经济 的底层地理。

🔑 关键认知：

  • Rus' ≠ Russia。 罗斯是9-13世纪的维京-斯拉夫融合政权。俄罗斯是15世纪后莫斯科公国演化出的现代国家。
  • 现代 俄罗斯、乌克兰、白俄罗斯 三个国家都源自基辅罗斯。就像法国、德国、意大利都源自查理曼帝国一样。
  • 中文"俄罗斯"多出来的"俄"字，来自蒙古语的转音——蒙古语不习惯以颤音 R 开头，所以在前面加了元音：O-ros → 斡罗思 → 俄羅斯。

🇬🇷 "希腊"在维京时代是什么？

在维京时代（8-11世纪），"希腊"不是一个独立国家——它是拜占庭帝国的核心领土之一。具体来说：

维度古代维京时代（8–11世纪）现代
政治归属城邦（雅典/斯巴达）→ 罗马行省拜占庭帝国的一部分独立主权国家（1832年至今）
语言古希腊语希腊语是拜占庭帝国的官方语言现代希腊语
宗教多神教东正教（源自君士坦丁堡）东正教（国教）

北欧人用 Grikkland（"希腊之地"）来指整个拜占庭帝国——因为讲希腊语的人统治着这个帝国。所以"从瓦良格人到希腊人之路"= 从瑞典到拜占庭的路线，"希腊人"就是拜占庭帝国的人。

维京时代的这个"东方世界"在今天分属六个现代国家：
