二次元绘画术语表

本术语表收录二次元绘画的核心术语，按类别分组。每条术语在首次出现的课程中会被引用和解释。 术语表随课程进度持续更新。

基础术语

线稿 Line Art
清理过的、干净的线条稿，是二次元绘画的基础骨架。好的线稿线条流畅，粗细有变化，闭合完整。
草稿 Sketch / Rough
绘画的初步阶段，用于确定构图、姿势和大致形状。线条可以凌乱，重在捕捉想法而非精致。
勾线 Inking
在草稿之上用干净的线条描出最终线稿的过程。在数字绘画中通常使用稳定器辅助。
打型 Block-in / Construction
用基本几何形（圆、方、三角）概括物体或人物的外形，建立正确的比例和位置关系。
控笔 Pen Control
对手写笔的精细控制能力，包括画直线、曲线、控制压力和速度。是线条质量的基础。

上色术语

平涂 Cel Shading / Flat Colors
二次元最常见的上色方式——先填充纯色底色，再加阴影和高光。分界清晰，不混色。
厚涂 Thick Painting / Atsunuri
模拟传统油画的上色方式，颜色融合过渡，体积感强。比平涂更费时。
灰度上色 Grayscale to Color / GtC
先在灰度下完成明暗关系（像黑白素描），再用叠加/渐变映射等方式转为彩色。
二分 / 影指定 Shadow Mapping
确定光源方向后，标记出暗面和亮面的分界线。这是二次元上色最关键的一步。
固有色 Base Color / Local Color
物体在均匀白光下的本来颜色，不受光影影响的纯色。
环境光 Ambient Light
来自周围环境反射的光，影响阴影的颜色（比如蓝天让阴影偏蓝）。

构图与透视

三分法 Rule of Thirds
将画面横竖各分三等份，重要元素放在交点或线上，是基础的构图法则。
一点透视 / 两点透视 1-Point / 2-Point Perspective
用来在平面上创造空间深度感的方法。一点透视有一个消失点，两点有两个。
消失点 Vanishing Point
透视中所有平行线汇聚的点，在画面内或画面外。
眼高线 Eye Level / Horizon Line
与观者视线高度对应的水平线，是所有透视的基线。

人体与角色

头身比 Head-to-Body Ratio
以头部高度为单位衡量角色身高。写实成人约 7–7.5 头身，二次元成男通常 7–9 头身。
三庭五眼 Three Courts and Five Eyes
中国传统面部比例法则：发际到眉毛 = 眉毛到鼻尖 = 鼻尖到下巴（三庭），脸宽 = 五只眼睛的宽度（五眼）。
动态线 Gesture Line / Line of Action
贯穿人体的主要运动趋势线，通常是 C 形或 S 形曲线，是姿势的灵魂。
十字线 Cross Contour
画头部时用的横纵辅助线，横线确定眼睛位置和朝向，纵线确定面部中线。

数字绘画工具

图层 Layer
数字绘画的核心概念，像叠在一起的透明玻璃，每层画不同内容，互不影响。
不透明度 Opacity
图层的透明程度，100% 完全可见，0% 完全透明。
混合模式 Blend Mode
控制上下图层颜色如何交互。常用有"正片叠底"(Multiply，用于阴影)和"叠加"(Overlay，用于光照)。
Alpha 锁定 Alpha Lock
锁定图层的透明区域，只允许在已有像素上作画，不会画出边界。
剪贴蒙版 Clipping Mask
让上层只在下层已有像素的范围内显示，类似 Alpha 锁定但更灵活。
稳定器 Stabilization / StreamLine
Procreate 和 CSP 中的功能，自动平滑手抖造成的线条波动。是数字绘画的重要辅助工具。
压感 Pressure Sensitivity
Apple Pencil 检测用力大小的能力，决定线条的粗细和透明度变化。
抖动修正 Stabilization (CSP)
CSP 中的术语，数值越高线条越平滑但延迟越大；通常设为 10–20。
