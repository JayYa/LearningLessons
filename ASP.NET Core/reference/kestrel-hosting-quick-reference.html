Kestrel 与托管速查表

参考文档 · 来源：第 2 课 · 基于 .NET 10

三层

① Kestrel（IServer）      监听 · 解析 HTTP/1.1/2/3 · TLS · 产出 HttpContext   —— 不认识 URL/端点/中间件
② 中间件管道              ForwardedHeaders → 异常 → HTTPS 重定向 → Routing → 认证 → 授权 → Endpoint
③ 端点（Endpoint）        MapGet lambda ≡ Controller Action，同一种东西

反向代理 → 转发头

头写回
X-Forwarded-ForConnection.RemoteIpAddress
X-Forwarded-ProtoRequest.Scheme
X-Forwarded-HostRequest.Host
X-Forwarded-PrefixRequest.PathBase

消费后的值从头里移除，原值搬到 X-Original-*。

using Microsoft.AspNetCore.HttpOverrides;

builder.Services.Configure<ForwardedHeadersOptions>(o =>
{
    o.ForwardedHeaders = ForwardedHeaders.XForwardedFor | ForwardedHeaders.XForwardedProto;
    o.KnownProxies.Add(IPAddress.Parse("10.0.0.5"));                          // 或
    o.KnownNetworks.Add(new IPNetwork(IPAddress.Parse("10.0.0.0"), 8));
});
var app = builder.Build();
app.UseForwardedHeaders();   // 最前面；必须在 UseHttpsRedirection / UseHsts / 认证之前
ForwardedHeadersOptions默认后果
ForwardedHeadersNone不设 = 未启用
KnownProxies / KnownNetworks仅 loopback非本机代理的头被静默忽略
ForwardLimit1只处理最右一跳
AllowedHosts空 = 全放行生产应限制，防 Host 伪造

ASPNETCORE_FORWARDEDHEADERS_ENABLED=true：启用 For+Proto 并清空 KnownProxies/KnownNetworks——仅限网络已隔离的云环境。

死循环：非 IIS 代理终止 TLS + 应用有 UseHttpsRedirection + 没配转发头 → ERR_TOO_MANY_REDIRECTS。IIS 进程外是唯一自动配好的场景。

容器（SDK 内置，无需 Dockerfile）

dotnet publish --os linux --arch x64 /t:PublishContainer
dotnet publish --os linux --arch x64 /t:PublishContainer -p ContainerArchiveOutputPath=./img.tar.gz   # 不需要 daemon
dotnet publish --os linux --arch x64 /t:PublishContainer -p ContainerRegistry=ghcr.io               # 推远程

docker run --rm -p 8000:8080 -e ASPNETCORE_ENVIRONMENT=Staging helloapi
MSBuild 属性默认（Web SDK，.NET 8+）
ContainerBaseImagemcr.microsoft.com/dotnet/aspnet:{TFM}
ContainerFamily—（可设 alpine）
ContainerRepository : ContainerImageTagAssemblyName 小写 : latest
ContainerPort从 ASPNETCORE_HTTP_PORTS 推断 → 8080
ContainerUserapp（非 root；UID 来自 APP_UID）
ContainerWorkingDirectory/app
ContainerEnvironmentVariable—（ASPNETCORE_ENVIRONMENT 未设 → Production）

需要 RUN（apt、建用户）→ 写 Dockerfile；否则 SDK 方式够用。
