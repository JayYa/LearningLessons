三个入口

参数语法说明
环境变量-e KEY=VALUE
-e KEY（从当前 shell 继承）
--env-file .env		覆盖镜像 ENV 的同名值。密码、端口、连接串都走这里。PowerShell 里值含空格用双引号：-e Greeting="Hi there"
bind mount-v "C:\abs\path:/container/path"
-v "${PWD}\config\x.json:/app/x.json"
-v "…:/path:ro"（只读）		宿主机文件/目录叠到容器路径上。必须绝对路径。宿主机路径不存在时 Docker 会创建一个空目录盖上去 —— 应用会崩，用 docker exec 名 ls -la /path 查。
named volume-v 卷名:/container/pathDocker 管理的存储，容器删了还在。第一次用自动创建。docker volume ls / inspect / rm。
端口-p 宿主机端口:容器端口只是转发。不改应用在容器里监听什么。

-v 冒号左边是什么？

左边长这样类型用途
C:\…、/…、${PWD}\…、.\…（不行，要绝对）bind mount配置文件、初始化脚本、开发时挂源码
pgdata、my-cache（纯名字）named volume数据库数据、上传文件 —— "我不关心存哪，只要别丢"

.NET 配置覆盖顺序

后加载的覆盖先加载的（官方顺序）：

appsettings.json  →  appsettings.{Environment}.json  →  环境变量  →  命令行参数
   （镜像里的，或 -v 挂进来的）                        （-e）          （CMD 后面的）
要改怎么写
顶层键 Greeting-e Greeting=Hi
嵌套键 Logging:LogLevel:Default-e Logging__LogLevel__Default=Debug（冒号在 Linux 环境变量里不合法，用双下划线）
连接串 ConnectionStrings:Default-e ConnectionStrings__Default="Host=pg;…"
监听端口（默认 8080）-e ASPNETCORE_HTTP_PORTS=5000
环境名-e ASPNETCORE_ENVIRONMENT=Development

完整例子

# hello-api：改端口 + 挂配置
docker run -d --rm --name hello -p 5000:5000 `
  -e ASPNETCORE_HTTP_PORTS=5000 `
  -v "${PWD}\config\appsettings.json:/app/appsettings.json" `
  hello-api:1.2

# postgres：必需 env + 持久化
docker run -d --name pg -p 5432:5432 `
  -e POSTGRES_PASSWORD=secret -e POSTGRES_DB=shop `
  -v pgdata:/var/lib/postgresql/data `
  postgres:17-alpine

PowerShell 续行是反引号 `，不是 \。
