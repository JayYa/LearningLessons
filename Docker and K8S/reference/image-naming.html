镜像命名与 registry

名字决定镜像从哪来、推到哪去。K8s 的 image: 字段用的也是这套规则。

四段名字

[registry/][namespace/]repo[:tag][@sha256:digest]

docker.io/library/postgres:17-alpine
localhost:5050/hello-api:1.2
ghcr.io/myorg/api:2.0
myuser/api:2.0                 ← 没有 registry 段 → docker.io/myuser/api:2.0
api@sha256:37da9bb7…           ← 按 digest 取，不可变
段省略默认识别规则
registrydocker.io第一段含 . 或 :，或等于 localhost，才算 registry
namespacelibrary（仅 Hub）Hub 上 = 用户名或组织名；私有 registry 可无
repo—小写字母、数字、- _ . /
taglatest最长 128 字符；latest 只是默认名，不自动存在、不代表最新

tag vs digest

tagdigest
是什么可移动的指针内容的 SHA256，不可变
谁决定你，docker tag / push内容算出来的
能被覆盖能，再 push 同名就指向新 digest不能
查看docker imagesdocker images --digests；docker image inspect x --format "{{.RepoDigests}}"
用途日常引用生产锁版本：image: repo@sha256:…

命令

命令做什么
docker tag src dst给同一 image ID 加名字。零拷贝
docker push name推到名字里的 registry。没有 --registry 参数
docker pull name拉取；已有则 Image is up to date
docker compose pull [svc]按 compose 文件里的 image: 拉
docker login [registry]不写 registry = Docker Hub。凭据存 Windows 凭据管理器
docker rmi name删一个名字；同 ID 的其他名字还在，最后一个名字删掉才删层
docker image ls --digests列出每个 tag 对应的 digest

本地 registry

docker run -d --name registry --restart unless-stopped -p 5050:5000 -v regdata:/var/lib/registry registry:2

curl http://localhost:5050/v2/_catalog              # 有哪些 repo
curl http://localhost:5050/v2/hello-api/tags/list   # 某 repo 有哪些 tag
curl -I http://localhost:5050/v2/hello-api/manifests/1.2   # Docker-Content-Digest 头
  • 明文 HTTP 只对 localhost 放行；用 IP/域名要在 Docker Desktop → Settings → Docker Engine 加 "insecure-registries": ["host:port"]。
  • 数据在 /var/lib/registry，不挂卷则 rm 容器即丢。
  • 删 tag 不在 API 默认开放范围，本地练习直接 docker volume rm regdata 重来。

push 内部流程

  1. 对每一层：HEAD /v2/<repo>/blobs/<digest> → 200 则 Layer already exists，404 则上传。
  2. 上传 config blob（镜像元数据 JSON）。
  3. PUT /v2/<repo>/manifests/<tag>：manifest 列出所有 blob 的 digest，tag 指向它。

推论：同一镜像推 N 个 tag，层只传一次；两个 tag 指向同一 digest 就是同一个东西。

Windows 保留端口

bind: An attempt was made to access a socket in a way forbidden by its access permissions = 端口被 Windows/Hyper-V 保留。查：

netsh interface ipv4 show excludedportrange protocol=tcp

本机 4904–5003 被占，所以 registry 映射到 5050 而不是 5000。换端口即可，没必要解除保留。
