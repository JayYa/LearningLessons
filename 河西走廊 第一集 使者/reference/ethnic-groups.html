河西走廊族群档案（公元前3世纪—公元1世纪）

这份参考档案收录了与河西走廊早期丝绸之路相关的六个主要族群的关键信息。每一条目均为高度压缩的"可查证事实"。在阅读任何关于丝绸之路的材料时，均可返回此处对照。

一、汉（Han）

时间范围公元前202年刘邦称帝—公元220年（本档案聚焦西汉：前202—公元9）
核心区域中原，首都长安（今西安）
经济形态农业帝国，以粟、麦为主粮，铁器牛耕普及
政治体制中央集权官僚制（郡县制+分封制残余），皇帝—三公—九卿
文字汉文（隶书—行政文书；小篆—正式碑铭）
关键君主汉高祖刘邦（前202—前195）、汉文帝（前180—前157）、汉景帝（前157—前141）、汉武帝刘彻（前141—前87）
与河西走廊的关系汉武帝前，河西走廊并非汉土。张骞"凿空"（前139—前126）后，霍去病于前121年攻占河西，汉设四郡（武威、张掖、酒泉、敦煌）。

二、匈奴（Xiongnu / Hsiung-nu）

时间范围公元前3世纪—公元1世纪（北匈奴西迁后逐渐消失于中国史书）
核心区域蒙古高原为中心，南至河套（今内蒙古鄂尔多斯），西至河西走廊及西域，北至贝加尔湖
族源与血统多源融合的政治联合体，非单一血统。核心人群混合华夏、印欧语系族群与北方土著血统。匈奴王级墓葬DNA显示父系Y染色体含R1a1a1b（可能与原始印欧人相关）。
经济形态游牧为主（马、牛、羊），但并非纯游牧——伊沃尔加城址等考古证明匈奴维持农业（小麦、黑麦、大麦）和手工业定居点
政治体制单于 → 左右贤王（各1） → 左右谷蠡王（各1） → 六"大"（左右大将、左右大都尉、左右大当户，共6人，军事指挥） + 左右骨都侯（共2人，异姓辅政/断狱，由呼衍氏、兰氏、须卜氏世袭） → 二十四长 → 千长/百长/什长。冒顿单于（约前209—前174）建立制度。
文字❌ 无自身文字。仅存约20余个汉文音译词汇（如"撑犁"=天/*täŋri，"孤涂"=子/*kut）。有Tamga（唐嘎/烙印符号）——氏族标识系统，类似家族纹章，不能记录语言，非文字。外交文书使用汉文，由降附汉人（中行说、卫律等）代笔。
行政方式口头命令 + 符信凭证。单于口头发出命令，由统治集团成员（贤王、谷蠡王、二十四长等）亲自传达，持符信（实物凭证/令牌）为身份证明。沿途各部为持符信使者提供驿马和饮食（"传送食"）——蒙古yam驿站制度的雏形。无文字官僚制，但命令传递效率极高。
语言争议极大，至今无共识。主要学说：突厥语系说（主流）、叶尼塞语系说（2025年新论）、蒙古语系说（少数）
关键单于头曼（？—前209）→ 冒顿（前209—前174，统一草原，白登之围）→ 老上（前174—前161，杀月氏王）→ 军臣（前161—前126）→ 伊稚斜（前126—前114，漠北之战）→ 呼韩邪（前58—前31，归汉）
与河西走廊的关系匈奴控制河西走廊数十年，作为西通西域、南逼汉朝的跳板。祁连山是匈奴的"圣山"。霍去病夺取河西后，匈奴哀歌："失我祁连山，使我六畜不蕃息；失我焉支山，使我妇女无颜色。"

三、月氏 / 贵霜（Yuezhi / Kushan）

时间范围公元前5世纪？—公元1世纪？（月氏阶段）；公元1世纪—4世纪（贵霜帝国阶段）
核心区域原居地：传统说河西走廊西部"敦煌、祁连间"——但西北大学王建新团队在东天山（今新疆巴里坤草原）发现了公元前5—前2世纪的月氏文化遗存，认为汉代"祁连山"实指东天山巴里坤山。争议未定。
迁徙后：伊犁河流域（短期）→ 阿姆河（妫水）流域 → 征服大夏（巴克特里亚）→ 建立贵霜帝国
族源与语言"吐火罗问题"：未解决。多数西方学者认为月氏操某种吐火罗语（印欧语系Centum支），亦有学者认为操伊朗语。塔里木盆地出土的吐火罗语文献（3—9世纪）是否即月氏后裔所操语言，尚无定论。
经济形态河西走廊时期：半游牧，可能控扼玉石贸易路线
巴克特里亚时期：定居化，农业+城市+贸易
政治体制西迁前：王权制。
西迁后：五翖侯（yabghu，叶护）分治 → 贵霜翖侯丘就却统一各部 → 贵霜帝国建立。迦腻色伽一世（Kanishka I）时代达鼎盛。
文字与记录✅ 唯一有自我书写的非汉族群！
• 大夏语（Bactrian）铭文：腊跋闼（Rabatak）铭文、Surkh Kotal铭文——用希腊字母书写
• 钱币铭文：极其丰富，从希腊铭文→希腊-犍陀罗双语→大夏语。神像多元（希腊、伊朗、印度、佛陀）
• 希腊-拉丁文献：斯特拉波、托勒密提及"Tokharoi"（吐火罗人）
关键人物月氏王（老上单于所杀）→ 丘就却（Kujula Kadphises，统一贵霜）→ 阎膏珍（Vima Kadphises，引入金币）→ 迦腻色伽一世（Kanishka I，鼎盛期，倡导佛教）
与张骞的关系张骞出使的目的地。但月氏"地肥饶，少寇，志安乐，又自以远汉，殊无报胡之心"——拒绝与汉结盟攻匈奴。

四、乌孙（Wusun）

时间范围公元前2世纪—公元5世纪（受柔然压迫西迁葱岭，此后消失于史书）
核心区域伊犁河流域、伊塞克湖周边（今哈萨克斯坦东南、吉尔吉斯斯坦北部）。冬都"赤谷城"尚未确确定位。
人口规模据《汉书》：63万人，胜兵18.88万——西域大国
族源与外貌颜师古注《汉书》描述"青眼赤须，状类猕猴"——表明欧罗巴人种特征。考古发掘骨骼为短颅欧罗巴人种。语言归属争议：印度-伊朗说（主流）、突厥说（基于狼祖神话的相似性）、混合说。
起源传说猎骄靡（Kunmo）幼时被弃荒野，"狼往乳之""乌衔肉置其侧"——与突厥阿史那氏族狼祖神话完全同构
文字❌ 无自身文字。所有记录均来自汉文史书和汉简（悬泉汉简中精确记录了乌孙使团人数、粮食配额、驿马数量）。
与汉的关系张骞第二次出使（约前119年）游说乌孙结盟。汉武帝以细君公主、解忧公主和亲。汉乌联军攻匈奴。悬泉汉简记录了冯嫽（中国第一位女性外交使节）往返于汉乌之间。

五、羌（Qiang）

时间范围商代（前1600—前1046年）就已出现在甲骨文中——中国文献中记录延续时间最长的非汉群体之一
核心区域青藏高原东北缘、祁连山南麓、青海湖周边、黄河上游的大夏河-洮河流域
族源与遗传2025年《Science Advances》基因组研究：羌人的最近共同祖先可追溯至约5300年前的古代黄河流域农民（仰韶文化相关），父系单倍群O-M175（O3a）。传统"羌=游牧西戎"形象需要修正——基因上近于农民，而非草原游牧民。
经济形态农牧混合、定居/半定居。考古文化（寺洼、四坝、辛店）均有农作物（粟、小麦）和家畜（猪骨表明定居生活），有独立的本地青铜冶炼技术。
文字❌ 无自身文字。甲骨文中的"羌"是商人的外部标签——羌俘是商王祭祀中最主要的人牲来源。许慎《说文》（汉代）释"羌"=羊+人→"西戎牧羊人也"，但这是汉代条件向商代的投射，受到现代学者的质疑。
"羌"标签的问题"羌"不是单一族群。它是华夏/汉人三千年间施加于广大西部人群的伞形术语。商代羌方≠周代姜戎≠汉代西羌≠现代羌族。蒲立本（1983）提出"羌"在甲骨文中可能是古藏语"仓"（tshang，骨系血族）的音借——强调氏族组织而非牧羊职业。
与河西走廊的关系羌人聚居在河西走廊南侧的祁连山南麓和青海地区。张骞归途试图走"羌中"路线却被匈奴再次俘虏，事后向汉武帝报告"羌中"路线不可行——"羌人恶之"。

六、大宛（Dayuan / Ferghana）

时间范围阿契美尼德波斯时期（前6世纪）已有定居点；希腊化时期建Alexandria Eschate（前329年）；汉文记录集中于前2—前1世纪
核心区域费尔干纳盆地（今乌兹别克斯坦、吉尔吉斯斯坦、塔吉克斯坦三国交界处），中亚最富庶的农业绿洲之一
人口特征《史记》描述为城市居民、深目高鼻（高加索人种特征）、"其俗与希腊-巴克特里亚同"、种植葡萄酿酒
文字与记录❌ 无本地文字传世。资料来源：
• 汉文：《史记》《汉书》
• 希腊-波斯背景：阿契美尼德帝国建立Cyropolis；亚历山大建Alexandria Eschate；斯特拉波提及希腊人扩张至"赛里斯"（Seres）附近
天马（汗血马）张骞报告大宛有"天马"（汗血马），额部有肉角状突起。汉赋赋予其宗教和宇宙论意义（昆仑山→西王母→不死之桃）。汉武帝为此发动两次远征（前104—前101年，李广利），最终获得约3000匹。波斯的尼萨马（Nisean horses）在阿契美尼德帝国也有类似的"神圣王权象征"地位。
与张骞的关系大宛是张骞逃脱匈奴后到达的第一个西域国家。大宛国王"闻汉之饶财，欲通不得"，热情接待张骞并为他提供向导和翻译，助其到达康居和大月氏。
