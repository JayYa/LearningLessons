HttpClient：两条正路

场景做法解决
有 DI（Host / ASP.NET Core）IHttpClientFactory，短命 clienthandler 共享 → 不耗尽；2 分钟轮换 → DNS 刷新
无 DI（脚本、小工具）长命单例 + SocketsHttpHandler { PooledConnectionLifetime = 2min }连接层定期重建 → DNS 刷新
❌ 每次 using new HttpClient()Socket 耗尽（TIME_WAIT）
❌ 裸 static HttpClientDNS 陈旧

IHttpClientFactory 三种用法

// NuGet: Microsoft.Extensions.Http
// ① 基本
builder.Services.AddHttpClient();
var client = factory.CreateClient();

// ② 命名
builder.Services.AddHttpClient("github", c =>
{
    c.BaseAddress = new Uri("https://api.github.com/");
    c.DefaultRequestHeaders.UserAgent.ParseAdd("my-app");
    c.Timeout = TimeSpan.FromSeconds(10);
})
.SetHandlerLifetime(TimeSpan.FromMinutes(5));
var client = factory.CreateClient("github");

// ③ 类型化（推荐）—— Transient，构造函数收 HttpClient
public sealed class GitHubClient(HttpClient http)
{
    public Task<Repo?> GetRepoAsync(string o, string n) => http.GetFromJsonAsync<Repo>($"repos/{o}/{n}");
}
builder.Services.AddHttpClient<GitHubClient>(c => c.BaseAddress = new Uri("https://api.github.com/"));

// 全局默认（所有客户端）
builder.Services.ConfigureHttpClientDefaults(b => b.AddStandardResilienceHandler());

IHttpClientBuilder 常用链式方法

方法作用
ConfigureHttpClient(c => ...)BaseAddress、默认头、Timeout
AddHttpMessageHandler<T>()挂 DelegatingHandler（出站中间件：认证、追踪）；T 注册为 Transient
ConfigurePrimaryHttpMessageHandler(() => ...)换底层 handler（代理、证书、Cookie）
UseSocketsHttpHandler((h, _) => h.PooledConnectionLifetime = ...).NET 5+，与 SetHandlerLifetime(Timeout.InfiniteTimeSpan) 搭配
SetHandlerLifetime(TimeSpan)handler 轮换周期，默认 2 分钟
AddStandardResilienceHandler()NuGet Microsoft.Extensions.Http.Resilience：重试 + 断路器 + 超时 + 限流
RedactLoggedHeaders([...])日志里遮蔽 Authorization 等头

生命周期规则

  • CreateClient 每次返回新 HttpClient；dispose 它不释放 handler
  • handler 按名字缓存，默认 2 分钟过期；过期后没人用了才释放
  • 类型化客户端 不要注入 Singleton——handler 不再轮换。Singleton 里注入 IHttpClientFactory
  • handler 有自己的 DI Scope，与请求 Scope 无关——DelegatingHandler 里别缓存 HttpContext 之类的东西
  • 需要 Cookie 会话的场景不适合工厂（CookieContainer 随 handler 共享 / 丢失）

预设与选项

// Web 预设 = camelCase + 不区分大小写 + 字符串数字。ASP.NET Core / GetFromJsonAsync 默认
private static readonly JsonSerializerOptions s_web = new(JsonSerializerDefaults.Web)
{
    DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull,
    Converters = { new JsonStringEnumConverter() },
    WriteIndented = false,
};
// ⚠️ Options 实例要缓存复用（static readonly），每次 new 重建元数据缓存

var json = JsonSerializer.Serialize(obj, s_web);
var obj  = JsonSerializer.Deserialize<Order>(json, s_web);
await JsonSerializer.SerializeAsync(stream, obj, s_web);              // 流式，不经过 string
var list = await JsonSerializer.DeserializeAsyncEnumerable<Item>(stream);  // 大数组逐项读

// HttpClient 扩展（System.Net.Http.Json，默认 Web 预设）
var repo = await http.GetFromJsonAsync<Repo>("repos/x/y");
var resp = await http.PostAsJsonAsync("items", item);
var back = await resp.Content.ReadFromJsonAsync<Item>();

特性

public sealed record Order(
    [property: JsonPropertyName("order_id")] int Id,        // 重命名
    [property: JsonIgnore] string? Secret,                  // 忽略
    [property: JsonRequired] string Customer,               // 缺失即抛（或 C# required）
    [property: JsonNumberHandling(JsonNumberHandling.AllowReadingFromString)] decimal Total,
    [property: JsonPropertyOrder(-1)] DateTimeOffset Created);

[JsonDerivedType(typeof(Circle), "circle")]                // 多态白名单，鉴别器默认 "$type"
[JsonDerivedType(typeof(Square), "square")]
[JsonPolymorphic(TypeDiscriminatorPropertyName = "kind")]   // 改鉴别器名
public abstract record Shape;

[JsonConverter(typeof(MyConverter))] public sealed class Foo { }   // 类型级自定义 converter
