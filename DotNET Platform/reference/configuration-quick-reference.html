管道模型

IConfigurationBuilder
  .AddJsonFile("appsettings.json")          ← 基础配置
  .AddJsonFile($"appsettings.{env}.json")   ← 环境覆盖（optional: true）
  .AddEnvironmentVariables()                ← K8s/容器注入
  .AddCommandLine(args)                     ← 命令行最高优先级
  .Build()
  → IConfigurationRoot

注册顺序 = 优先级（最后胜出）

顺序源典型用途
1（最低优先级）appsettings.json所有环境的通用默认值
2appsettings.{ENV}.json开发/预发布/生产——环境差异
3AddEnvironmentVariables()K8s ConfigMap、Docker、12-Factor App
4（最高优先级）AddCommandLine(args)CI/CD 传入参数，或开发时快速覆盖

读取方式速查

IConfiguration config = builder.Build();

// ── 基本读取 ──
config["A:B:C"]                         // string? —— 返回 null 如果不存在
config.GetSection("A:B")                // IConfigurationSection —— 切子节点

// ── 类型转换 ──
config.GetValue<int>("Timeout")         // int —— 不存在返回 default(int) = 0
config.GetValue<int>("Timeout", 30)     // int —— 不存在返回 30
config.GetValue<bool>("Enabled")        // bool —— "true"/"false" → bool
config.GetValue<Uri>("ServiceUrl")      // Uri —— 自动调用 TypeConverter

// ── 绑定到对象 ──
var opts = new MyOptions();
config.GetSection("MyOptions").Bind(opts);
// 或
var opts = config.GetSection("MyOptions").Get<MyOptions>();

环境变量命名规则

// JSON 中的结构：
// { "Database": { "ConnectionString": "..." } }

// 环境变量（Windows / Docker / Linux 都支持）：
Database__ConnectionString=Server=prod;...      // 双下划线 __

// 命令行参数：
--Database:ConnectionString="Server=prod;..."   // 冒号 :

// 两者都会映射到同一个 key：config["Database:ConnectionString"]

Options 模式三接口速查

接口生命周期热重载变更回调何时用
IOptions<T> Singleton ❌ ❌ 不该在运行时变的配置（密钥、SDK 初始化参数）
IOptionsSnapshot<T> Scoped ✅ ❌ Scoped 服务需要热重载——每个请求自动拿新配置
IOptionsMonitor<T> Singleton ✅ ✅ Singleton 需要热重载 + 配置变更时自动触发操作

Options 注册速查

// ── 基本注册 ──
services.Configure<MyOptions>(config.GetSection("MySection"));

// ── 代码覆盖 ──
services.Configure<MyOptions>(opts =>
{
    config.GetSection("MySection").Bind(opts);
    opts.OverrideThis = 42;  // 强制覆盖 JSON 中的值
});

// ── Named Options ──
services.Configure<MyOptions>("Redis", config.GetSection("Cache:Redis"));
services.Configure<MyOptions>("Local", config.GetSection("Cache:Local"));
// 注入：IOptionsSnapshot<MyOptions> opts; opts.Get("Redis");

// ── 校验（Data Annotations） ──
services.AddOptions<MyOptions>()
        .Bind(config.GetSection("MySection"))
        .ValidateOnStart();
// POCO 上标记 [Required]、[Range]、[RegularExpression]

// ── 校验（自定义逻辑） ──
services.AddOptions<MyOptions>()
        .Bind(config.GetSection("MySection"))
        .Validate(opts => opts.Max > 0, "Max 必须大于 0");

// ── 校验（IValidateOptions<T>——注入其他服务） ──
services.AddSingleton<IValidateOptions<MyOptions>, MyOptionsValidator>();

// ── PostConfigure（在所有 Configure 之后运行） ──
services.PostConfigure<MyOptions>(opts =>
{
    if (string.IsNullOrEmpty(opts.Url))
        opts.Url = "https://default.example.com";
});
