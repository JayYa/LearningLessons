GC 模式配置

配置项csproj 属性runtimeconfig.json环境变量默认值
Server GC ServerGarbageCollection System.GC.Server DOTNET_gcServer false（控制台）
true（ASP.NET）
Background GC ConcurrentGarbageCollection System.GC.Concurrent DOTNET_gcConcurrent true
Server GC 堆数 —（用 RuntimeHostConfigurationOption） System.GC.HeapCount DOTNET_GCHeapCount CPU 核数
内存节约模式 — System.GC.ConserveMemory DOTNET_GCConserveMemory 0（不启用）
堆内存硬上限 — System.GC.HeapHardLimit DOTNET_GCHeapHardLimit 容器：20MB 或 75%
内存负载触发阈值 — System.GC.HighMemoryPercent DOTNET_GCHighMemPercent 90% 
<!-- csproj 示例：控制台服务切 Server GC + 限制堆数 -->
<PropertyGroup>
  <ServerGarbageCollection>true</ServerGarbageCollection>
</PropertyGroup>
<ItemGroup>
  <RuntimeHostConfigurationOption Include="System.GC.HeapCount" Value="4" />
</ItemGroup>

三种编译部署模式

JIT

即时编译

运行时编译 IL → 机器码
启动：慢
峰值性能：最高
体积：最小
运行时依赖：需要

R2R

ReadyToRun

发布时预编译
启动：较快
峰值性能：高
体积：中等
运行时依赖：需要

NativeAOT

原生 AOT

发布时全编译
启动：极快
峰值性能：高
体积：大
运行时依赖：不需要

模式csproj 属性发布命令关键限制
JIT（默认） — dotnet publish 无
R2R PublishReadyToRun dotnet publish -p:PublishReadyToRun=true 需指定 RID；跨平台需分别发布
NativeAOT PublishAot dotnet publish -r win-x64 无 Assembly.LoadFile、无 Emit、需 C++ 工具链
