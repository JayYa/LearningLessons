一句话区分

Span<T>Memory<T>
类型ref structstruct
存活范围只能在栈上栈上 / 堆上（可作为类字段）
async 方法❌ 不能跨 await✅ 可以
作为字段❌ 只能作为 ref struct 的字段✅ 任意类型的字段
装箱❌ 不允许✅ 但会分配在堆上
lambda 捕获❌ 不允许✅ 允许
迭代器 (yield)❌ 不允许✅ 允许
性能更快（无间接层）.Span 属性有一层间接

创建方式

// ========== Span<T> ==========

// 从数组
Span<byte> s1 = new byte[1024].AsSpan();
Span<byte> s2 = new byte[1024];              // 隐式转换

// 从数组切片
Span<byte> s3 = array.AsSpan(10, 100);       // [10..110)

// 从字符串 (ReadOnlySpan)
ReadOnlySpan<char> s4 = "hello".AsSpan();
ReadOnlySpan<char> s5 = "hello".AsSpan(1, 3);// "ell"

// 栈上分配
Span<int> s6 = stackalloc int[32];
Span<byte> s7 = stackalloc byte[64];         // 类型推断

// 从非托管指针
Span<byte> s8 = new Span<byte>(ptr, length); // unsafe

// 从 Memory
Span<byte> s9 = memory.Span;

// ========== Memory<T> ==========

// 从数组
Memory<byte> m1 = new byte[1024].AsMemory();
Memory<byte> m2 = new byte[1024];            // 隐式转换

// 从数组切片
Memory<byte> m3 = array.AsMemory(10, 100);

// 从字符串
ReadOnlyMemory<char> m4 = "hello".AsMemory();

// 从 MemoryManager (池化/非托管)
Memory<byte> m5 = new NativeMemoryManager(1024).Memory;

常用操作

Span<int> s = stackalloc int[] { 1, 2, 3, 4, 5, 6, 7, 8 };

// 切片 (不复制)
var first4 = s.Slice(0, 4);        // [1,2,3,4]
var last4 = s.Slice(4);            // [5,6,7,8]
var middle = s[2..6];              // [3,4,5,6] (C# range syntax)

// 查找
int idx = s.IndexOf(5);            // 4
bool hasNegative = s.ContainsAny(searchValues);

// 修改
s.Fill(42);                        // 全部填 42
s.Clear();                         // 全部填 default

// 拷贝
var dest = new Span<int>(new int[8]);
s.CopyTo(dest);                    // 整段复制

// 比较
bool eq = s.SequenceEqual(other);  // 逐元素比较

// 转回数组 (这会分配!)
int[] arr = s.ToArray();           // ⚠️ 产生 GC 分配

性能陷阱

陷阱错误代码正确代码原因
Span 转 string span.ToString() new string(span) 或直接用 ReadOnlySpan<char> ToString() 返回类型名，不是内容
不必要的 ToArray span.ToArray()[0] span[0] ToArray() 产生堆分配
Span 装箱 object o = span; 不允许（编译器错误） ref struct 禁止装箱
捕获 Span 到闭包 Task.Run(() => span[0]); 先 CopyTo 到堆数组，或改用 Memory<T> Span 不能在 lambda 中存活
async 中用 Span 跨 await await Task.Yield(); span[0] = 1; 改用 Memory<T>，同步段取 .Span 编译器 CS4012

Framework 4.8 API → 现代 .NET Span API

Framework 4.8 写法（分配）现代 .NET 写法（零分配）
str.Substring(0, 10) str.AsSpan(0, 10)
str.Split(',')[0] str.AsSpan().IndexOf(','); str.AsSpan(0, idx)
new string(chars.Where(...).ToArray()) 用 Span<char> 就地修改，或 string.Create()
Encoding.UTF8.GetString(bytes) Encoding.UTF8.GetString(span)（Span 重载）
File.ReadAllBytes(path) 用 Stream.ReadAsync(Memory<byte>) + ArrayPool
int.Parse(str.Substring(2,5)) int.Parse(str.AsSpan(2, 5))
new ArraySegment<byte>(buf, 0, 100) buf.AsSpan(0, 100)

选择决策树

你需要操作内存/切片
│
├── 在同步方法里，作为局部变量？
│   └── Span<T> ✅
│
├── 作为方法的参数？
│   ├── 同步方法 → Span<T> 或 ReadOnlySpan<T>
│   └── 异步方法 → Memory<T> 或 ReadOnlyMemory<T>
│       （在方法里第一个 await 之前取 .Span 处理）
│
├── 作为类的字段？
│   └── Memory<T> ✅
│       （Span<T> 不能做类字段）
│
├── 需要在 lambda / closure 中使用？
│   └── Memory<T> ✅
│
└── 性能关键路径，确定不跨方法调用？
    └── Span<T> ✅（无间接层）

ArrayPool：和 Span 配合减少 GC 压力

// 经典模式：租用 → 使用 → 归还
byte[]? rented = null;
try
{
    rented = ArrayPool<byte>.Shared.Rent(4096);  // 至少 4096 字节
    Span<byte> buffer = rented.AsSpan(0, 4096);   // 只用前 4096
    // ... 处理 buffer ...
}
finally
{
    if (rented is not null)
        ArrayPool<byte>.Shared.Return(rented);   // 归还（不清除内容）
}
⚠️ ArrayPool.Return 不会清除数组内容。下一个租用者可能读到脏数据。 如果你存放了敏感信息，归还前用 span.Clear() 覆盖。
