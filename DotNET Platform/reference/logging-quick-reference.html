模块：日志  |  速查参考

一条日志 = 一个事件

字段来源用途
CategoryILogger<T> → T 全名过滤（前缀匹配）
LevelLogXxx 方法名 / [LoggerMessage(Level)]过滤（阈值）
EventId可选整数 + 名字归组同类事件
State模板占位符 → 命名字段结构化查询
Exception独立参数，不进模板堆栈
ScopeBeginScope，AsyncLocal 传播上下文字段（RequestId、OrderId）

级别

Level值用法
Trace0原始数据、可能含敏感信息，生产禁用
Debug1开发调试，量大
Information2一般流程（默认阈值）
Warning3意外但未失败
Error4当前操作失败
Critical5应用级失败，需立即处理
None6静音（只用于配置）

消息模板规则

logger.LogInformation("Order {OrderId} took {Elapsed:N0}ms", id, ms);
//  ✅ 占位符用名字、PascalCase        ✅ 支持格式说明符
//  ⚠️ 参数按【位置】填入，名字只决定字段名
//  ❌ 不要 $"..." 插值（CA2254）—— 字段丢失、级别没开也分配
//  {{ }} 输出字面大括号

logger.LogError(ex, "Order {OrderId} failed", id);   // 异常是独立参数（第一个）
if (logger.IsEnabled(LogLevel.Debug)) { ... }        // 昂贵参数先判断

[LoggerMessage] 源生成器（推荐写法）

public sealed partial class OrderService(ILogger<OrderService> logger)   // 类 partial；.NET 9+ 认主构造函数
{
    [LoggerMessage(EventId = 1001, Level = LogLevel.Information, Message = "Order {OrderId} took {Elapsed}ms")]
    private partial void LogProcessed(int orderId, long elapsed);         // 方法 partial void

    [LoggerMessage(EventId = 1002, Level = LogLevel.Error, Message = "Order {OrderId} failed")]
    private partial void LogFailed(Exception ex, int orderId);            // 第一个 Exception 自动当异常

    [LoggerMessage(EventId = 1003, Message = "Retry {Attempt}")]
    private partial void LogRetry(LogLevel level, int attempt);           // 省略 Level → 运行时传入
}

// 静态版本（集中放在 static partial class Log）
[LoggerMessage(EventId = 1, Level = LogLevel.Warning, Message = "Slow query {Ms}ms")]
public static partial void SlowQuery(this ILogger logger, long ms);      // this → 扩展方法

// 规则：占位符与参数按名字匹配（不分大小写）；不能 params / ref struct；名字不能下划线开头
// 收益：零装箱、零 object[]、先查 IsEnabled、强类型、EventId 重复有警告

appsettings.json 的 Logging 节

{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft": "Warning",                      // 前缀匹配
      "Microsoft.Hosting.Lifetime": "Information", // 更长前缀优先
      "System.Net.Http.HttpClient": "Warning",
      "Microsoft.EntityFrameworkCore.Database.Command": "Information"   // 只看 SQL
    },
    "Console": {                                   // Provider 别名：Console / Debug / EventSource / EventLog
      "IncludeScopes": true,                       // 控制台显示 Scope
      "FormatterName": "json",                     // simple | systemd | json
      "LogLevel": { "Default": "Warning" }         // Provider 级规则覆盖全局
    }
  }
}
// 环境变量覆盖：Logging__LogLevel__Default=Debug
// 文件热重载：改文件即生效，不用重启

规则选择（每个 Provider × Category）：
① 有指定该 Provider 的规则？用它们；否则用未指定 Provider 的
② 取 Category 前缀最长匹配；没有 → Default
③ 仍多条 → 最后一条
④ 一条都没 → SetMinimumLevel（默认 Information）

代码配置

builder.Logging.ClearProviders();                      // 去掉默认 4 个
builder.Logging.AddSimpleConsole(o => o.IncludeScopes = true);
builder.Logging.AddJsonConsole();                      // 容器 / 日志采集
builder.Logging.SetMinimumLevel(LogLevel.Warning);     // 兜底阈值
builder.Logging.AddFilter("Microsoft", LogLevel.Warning);
builder.Logging.AddFilter<ConsoleLoggerProvider>("MyApp", LogLevel.Debug);   // Provider 级
builder.Logging.AddOpenTelemetry(o => o.AddOtlpExporter());

// Serilog（NuGet: Serilog.Extensions.Hosting + Sinks）
builder.Services.AddSerilog(cfg => cfg
    .ReadFrom.Configuration(builder.Configuration)     // 读 "Serilog" 节
    .Enrich.FromLogContext()
    .WriteTo.Console()
    .WriteTo.File("logs/app-.log", rollingInterval: RollingInterval.Day));
// 业务代码依旧只注入 ILogger<T>

Scope

using (logger.BeginScope(new Dictionary<string, object> { ["OrderId"] = id, ["UserId"] = uid }))
{
    // 此异步调用链内、任何类的 ILogger 写的日志都附带 OrderId / UserId
    await ProcessAsync();
}
// 控制台需 IncludeScopes = true；结构化 Provider 直接存字段
// 不要放大对象；字典优于模板字符串
